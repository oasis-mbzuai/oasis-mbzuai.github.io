Oracles · Assurance · Safety for Intelligent Systems

Agents are the new software.

Software used to be written line by line by people. Increasingly it is written, and run, by AI agents. OASIS studies them as a new kind of software: how they behave, how to build better ones, and how to know the code they produce is correct.

{{ site.tagline }}

The premise

Code is not correct because an agent wrote it. A system that reports its own success is not evidence of anything.

What we look for instead is something a sceptic could check: a counterexample, a proof, a trace that replays. We build the tools that produce those, and we try hard to break our own.

In a desert, the useful skill is telling water from the appearance of water.
